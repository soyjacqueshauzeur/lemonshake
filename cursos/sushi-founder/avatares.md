# Avatares de Sushi Founder

Tres compradores distintos para el mismo curso. Cada uno tiene su landing:
`chef.html`, `regalo.html` y `negocio.html`. La página base (`index.html`) sigue
siendo la versión general. Las tres respetan la paleta y los estilos ya establecidos
del sitio: no agregan CSS ni colores nuevos.

---

## 1. El que ya cocina y quiere pulir técnica

**Landing:** `chef.html`

| | |
| --- | --- |
| **Quién es** | Cocinero, sous chef, ayudante de cocina o aficionado avanzado. 24–45 años. Ya hizo rolls alguna vez. |
| **Dónde está** | Cocinas de restaurante, cafeterías, catering, cocina de casa con buen equipo. |
| **Qué quiere** | Que le salga igual todas las veces. Entender el arroz, el corte y la presión, no memorizar recetas. |
| **Qué le duele** | Resultados inconsistentes, arroz pasado, cortes irregulares, falta de orden técnico. |
| **Qué teme** | Que el curso sea "para principiantes" y le haga perder tiempo. |
| **Qué lo convence** | Orden por técnica, medidas, cámara cerca, certificado, acceso de por vida. |
| **Objeción principal** | "¿Esto me sirve a mi nivel?" → Sí: puede ir directo a arroz, cortes, enrollado o salsas. |
| **Mensaje** | "Ya haces sushi. Ahora hazlo con técnica de cocina profesional." |
| **Anuncio** | Video corto de un corte o del arroz, texto: "se te desarma el roll por esto". |

## 2. El que regala o quiere un plan para compartir

**Landing:** `regalo.html`

| | |
| --- | --- |
| **Quién es** | Pareja, familia o grupo de amigos. 28–55 años. Compra para otro o para hacer juntos. |
| **Dónde está** | Buscando regalo de cumpleaños, aniversario, Navidad, o plan de fin de semana. |
| **Qué quiere** | Una experiencia, no otro objeto. Algo que se use y se recuerde. |
| **Qué le duele** | Regalos que quedan en un cajón, planes repetidos, no saber qué regalar a alguien que tiene todo. |
| **Qué teme** | Que la otra persona no lo use o que sea complicado. |
| **Qué lo convence** | Acceso inmediato, recetario, se puede hacer esta semana, acceso de por vida, precio de una salida. |
| **Objeción principal** | "¿Y si no cocina?" → Empieza desde cero: herramientas, arroz y recetas con medidas. |
| **Mensaje** | "Regala una experiencia, no otra cosa que se guarda en un cajón." |
| **Anuncio** | Foto de dos personas cocinando o mesa con rolls, texto: "el regalo que sí se usa". |

## 3. El que quiere vender

**Landing:** `negocio.html`

| | |
| --- | --- |
| **Quién es** | Persona que quiere ingresos extra o ya vende comida desde casa. 25–45 años. |
| **Dónde está** | Cocina doméstica, ferias, pedidos por WhatsApp, pequeños eventos. |
| **Qué quiere** | Una habilidad con salida real y un método para producir sin improvisar. |
| **Qué le duele** | No saber costear, resultados distintos en cada pedido, desperdicio, menú que no puede cumplir. |
| **Qué teme** | Invertir y no vender. |
| **Qué lo convence** | Técnica + recursos de producción, listas de compras, plantillas, certificado. |
| **Objeción principal** | "¿Sirve para vender?" → Sí, con plantillas y recursos; el curso no garantiza ingresos. |
| **Mensaje** | "Aprende la técnica y el método para vender sushi desde tu cocina." |
| **Anuncio** | Video de producción en serie o empaque, texto: "cobra bien, no a ojo". |

## Qué cambia en cada landing

| Elemento | Chef | Regalo | Negocio |
| --- | --- | --- | --- |
| Sección nueva | Diagnóstico técnico (4 puntos) | Cómo se regala + 4 planes | Ruta de 4 semanas + antes de vender |
| Prueba social | "quienes ya cocinan sushi" | "alumnos que lo hicieron en casa" | "alumnos que empezaron en casa" |
| Tono | Directo, técnico | Cálido, de plan | Práctico, de negocio |
| CTA | Quiero pulir mi técnica | Quiero regalarlo | Quiero aprender a vender sushi |

## Reglas de honestidad

- No se prometen ingresos ni resultados de venta.
- No se inventan módulos: los tres ángulos usan el mismo contenido real del curso.
- Las reseñas son las mismas reseñas verificadas de Hotmart.
- El precio es el mismo en las tres páginas: USD $35 (antes USD $45).

## Cómo se llega a cada una

No están enlazadas en la navegación. Se accede desde el limón del footer
(modal "Versiones de esta página") o directamente por URL, y están en
`sitemap.xml` para que Google las descubra.
